# ADR-001 — DB dùng chung + FORCE RLS; 5 vai trò DB

- Trạng thái: Đã áp dụng ở GĐ0 (theo master-plan v2.0 mục 5).
- Quyết định: một Postgres 16 dùng chung, mọi bảng có `tenant_id` bật
  `ENABLE` + `FORCE ROW LEVEL SECURITY` + policy `tenant_isolation`.
  Không role ứng dụng nào có `BYPASSRLS`, trừ `app_platform` (chỉ M01).
- Vai trò: `app_owner` (migration), `app_user` (API), `app_worker`
  (worker/sweeper), `app_platform` (M01, sau 2FA), `app_sys_definer`
  (chỉ sở hữu hàm `sys.*`, NOLOGIN).
- Hệ quả: kể cả code ứng dụng có lỗi, RLS vẫn chặn đọc chéo tenant;
  migration và bootstrap roles phải tách riêng, không chạy từ app.
