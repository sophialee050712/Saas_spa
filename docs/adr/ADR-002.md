# ADR-002 — Tác vụ xuyên tenant chỉ qua hàm sys.* SECURITY DEFINER

- Trạng thái: Đã áp dụng ở GĐ0 (theo master-plan v2.0 mục 5).
- Quyết định: việc bắt buộc nhìn qua nhiều tenant (giải slug thành
  tenant, vớt outbox) chỉ đi qua hàm trong schema `sys`, mỗi hàm một việc,
  `search_path` cố định, thu hồi PUBLIC, chỉ cấp EXECUTE cho role cần dùng.
- Hàm GĐ0: `sys.resolve_tenant`, `sys.claim_pending_outbox`,
  `sys.requeue_stuck_outbox`. Thêm hàm mới phải có ADR mới.
